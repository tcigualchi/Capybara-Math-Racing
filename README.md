# 🦫 CopyBara Math

**CopyBara Math** é um aplicativo educacional gamificado desenvolvido para tornar o aprendizado de operações matemáticas básicas mais divertido, interativo e acessível.

O jogo trabalha principalmente com **adição, subtração e multiplicação**, utilizando desafios progressivos, efeitos visuais, feedback sonoro e elementos de gamificação para tornar a experiência mais envolvente.

## 🎯 Objetivo

O principal objetivo do **CopyBara Math** é auxiliar no aprendizado e na prática de matemática de forma leve e dinâmica, permitindo que o usuário desenvolva suas habilidades por meio de desafios adaptados ao seu nível de conhecimento.

O aplicativo possui três níveis de dificuldade:

- 🟢 **Fácil**
- 🟡 **Médio**
- 🔴 **Difícil**

Dessa forma, o jogo pode ser utilizado tanto por quem está começando a aprender operações matemáticas quanto por quem deseja praticar cálculos com desafios mais avançados.

## 🎮 Experiência de Jogo

Durante as partidas, o jogador recebe diferentes desafios matemáticos e precisa responder corretamente para aumentar sua pontuação e continuar avançando.

O sistema utiliza elementos visuais e sonoros para tornar cada ação mais perceptível e divertida.

Respostas corretas são recompensadas, enquanto erros podem afetar o sistema de vidas, incentivando o jogador a prestar atenção e melhorar seu desempenho.

As dicas e explicações ajudam o usuário a compreender os cálculos em vez de apenas tentar acertar as respostas.

## 🧠 Conceito Educacional

O **CopyBara Math** foi pensado para unir dois conceitos:

**Educação + Gamificação**

Em vez de apresentar apenas exercícios tradicionais, o aplicativo busca transformar a prática matemática em uma experiência semelhante a um jogo.

Isso permite trabalhar conceitos como:

- raciocínio lógico;
- cálculo mental;
- reconhecimento de operações;
- tomada rápida de decisões;
- aprendizado por repetição;
- progressão de dificuldade.
